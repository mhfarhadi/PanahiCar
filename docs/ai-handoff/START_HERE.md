# MayaHamrah — AI / Developer Handoff

## هدف این پوشه
این پوشه باید اجازه دهد پروژه بدون دسترسی به ChatGPT قبلی، حساب قبلی یا تاریخچه گفتگو ادامه پیدا کند.

اگر یک ChatGPT، AI Agent یا برنامه‌نویس جدید این پروژه را تحویل گرفت:

1. ابتدا تمام فایل‌های همین پوشه را بخواند.
2. سپس `git log --oneline -20` را بررسی کند.
3. سپس `git status` را بررسی کند.
4. ساختار واقعی کد را قبل از هر تغییر بررسی کند.
5. از `PROJECT_STATE.md` به‌عنوان وضعیت فعلی استفاده کند.
6. تصمیمات ثبت‌شده در `DECISIONS.md` را بدون دلیل قوی نقض نکند.
7. کارهای آینده را از `BACKLOG.md` ادامه دهد.

## روش همکاری با صاحب پروژه

- زبان گفتگو: فارسی.
- در کار ترمینال: دقیقاً یک دستور در هر مرحله بده.
- بعد از هر دستور منتظر خروجی کاربر بمان.
- بدون دیدن کد واقعی، patch حدسی نده.
- از patchهای وابسته به whitespace و `text.replace()` چندخطی شکننده اجتناب کن.
- ترجیح: marker معنایی، line-based patch، parser-friendly patch یا بازنویسی کنترل‌شده بخش مشخص.
- بعد از تغییر مهم:
  1. syntax/build/test
  2. تست دستی کاربر
  3. `git diff --check`
  4. update handoff docs
  5. commit
- checkpoint فقط زمانی گرفته شود که کاربر نتیجه را تست کرده باشد.
- هیچ migration یا داده مهمی بدون اجازه حذف نشود.
- برای عملیات destructive از کاربر تأیید گرفته شود.

## دستور شروع پیشنهادی برای AI جدید

متن زیر را می‌توان عیناً به AI جدید داد:

«این پروژه MayaHamrah را قبلاً با یک ChatGPT دیگر توسعه داده‌ام.
هیچ حافظه‌ای از گفتگوهای قبلی فرض نکن.
ابتدا تمام فایل‌های `docs/ai-handoff/` را کامل بخوان.
بعد `git log --oneline -20` و `git status` و کد مربوط به کار بعدی را بررسی کن.
`PROJECT_STATE.md` وضعیت فعلی پروژه و `DECISIONS.md` تصمیمات قطعی محصول هستند.
در ترمینال فقط یک دستور در هر مرحله بده و منتظر خروجی من بمان.
بدون بررسی فایل واقعی patch حدسی نده.
از آخرین checkpoint امن ادامه بده.»
